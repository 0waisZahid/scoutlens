# Security policy

## Reporting a vulnerability

Please report security issues privately using the repository's **Security → Advisories → Report a vulnerability** feature on GitHub. Do not disclose suspected vulnerabilities in public issues. If private vulnerability reporting is unavailable, contact the repository maintainer through a private channel before sharing technical details.

Maintainers should enable GitHub private vulnerability reporting so that the repository provides a direct reporting route.

## Supported versions

Security fixes are applied to the latest version on the default branch.
